# 研数 · 321 套刷题台

电脑上双击 `启动刷题网页.cmd` 即可使用。网页、题库、公式字体和做题进度均保存在本机。

手机离线使用时，只需把 `研数321套刷题.html` 传到手机后，用支持本地 HTML 的浏览器打开。这个单文件已经包含全部题库、公式引擎和字体，不需要联网，也不需要与电脑处于同一 Wi-Fi。

## 功能

- 按系列、年份、数学一/二/三、试卷编号筛选
- 题号导航、选择题作答、随机抽题
- 收藏、掌握进度与本题笔记本地保存
- 键盘快捷键：方向键切题，数字 1–4 选择选项，`F` 收藏

题库没有答案和解析，因此选择选项只用于记录作答。TikZ 题图暂以图形说明及源码显示。

## 重新生成题库

题库源数据更新后，在 PowerShell 中运行：

```powershell
.\scripts\build-data.ps1 -SourceDirectory '题库目录' -OutputFile '.\dist\papers-data.js'
node .\scripts\build-standalone.mjs
```
