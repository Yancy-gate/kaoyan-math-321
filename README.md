# 研数 · 321 套刷题台

一个可离线使用的考研数学刷题网页，内含市面主流模拟卷 321 套试卷、7062 道题，覆盖数学一、数学二和数学三。

## 两种版本

- **电脑版**：进入 [`刷题网页/dist`](刷题网页/dist) 后打开 `index.html`，或在 Windows 上双击 `刷题网页/启动刷题网页.cmd`。
- **手机单文件版**：将 [`刷题网页/研数321套刷题.html`](刷题网页/研数321套刷题.html) 下载到手机，用支持本地 HTML 的浏览器打开；无需联网。

## 功能

- 按系列、年份、科目和试卷筛选
- 数学公式离线渲染
- 选择题作答、随机抽题和题号导航
- 收藏、掌握进度与本题笔记本地保存

题库源数据不包含答案和解析。TikZ 题图目前显示图形说明和源码。
